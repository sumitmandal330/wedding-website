# Project: ABINASH & Shikha Premium Wedding Invitation

## Project Goal
Build a premium, cinematic, interactive wedding invitation website using React.js and Vite. This is a creation project, not a learning tutorial. Implement working code directly in the existing project.

## Wedding Details
- Groom: ABINASH
- Bride: Shikha
- Wedding date: 5 December 2026
- Venue: Co-operative Colony, Bokaro, Jharkhand
- Events: Haldi, Mehndi, Sangeet, Shaadi
- Couple photos available: approximately 7–8

## Required Experience
1. Welcome screen with elegant typography, animated floral elements, couple names, wedding date, and an Enter Invitation button.
2. On entering, transition smoothly to a Lord Ganesha blessing screen.
3. Allow users to touch/tap the feet area of the Ganesha artwork. Trigger a golden glow, particles, blessing text, and optional bell sound.
4. Transition to a royal entrance featuring two interactive doors.
5. One door opens the Engagement section.
6. The other door opens the Wedding section with all rituals, dates, times, venue, gallery, countdown, and family invitation message.
7. Include a photo gallery, Google Maps directions, and optional background music with a visible mute/play control.
8. Provide a graceful final invitation screen.

## Visual Direction
- Luxury Indian wedding aesthetic.
- Ivory, champagne gold, deep maroon, warm cream, and subtle floral accents.
- Elegant Indian-inspired typography.
- Cinematic transitions, tasteful particles, soft glows, layered backgrounds, and polished interactions.
- Mobile-first design, responsive on phones, tablets, and desktops.
- Avoid generic dashboard layouts, unnecessary navigation bars, and excessive cards.

## Technical Requirements
- Use the existing React + Vite project.
- Use Framer Motion for animations and Lucide React for icons where appropriate.
- Use React Router only if separate URL routes are beneficial; a state-driven cinematic experience is acceptable.
- Use reusable components and clean, maintainable code.
- Ensure touch and click interactions work on mobile and desktop.
- Respect prefers-reduced-motion where practical.
- Optimize images and avoid unnecessary large dependencies.
- Audio must start only after a user interaction and always have a mute control.
- Never invent missing event dates, timings, engagement details, or family names. Use clearly editable placeholders until supplied.
- Keep wedding content in a centralized configuration file so it can be changed easily.
- Do not require paid APIs or paid assets.
- Ensure npm run build completes successfully.

## Working Rules
- Inspect the existing project before modifying files.
- Implement working features, not just mockups or TODO comments.
- Create or modify files directly.
- Run the production build and fix errors.
- Do not replace working code unnecessarily.
- If an asset is missing, use a tasteful local placeholder and explain which asset should be replaced.
- Prioritize a complete, polished, usable experience over adding unnecessary features.
