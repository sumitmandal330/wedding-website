# Abinash & Shikha Wedding Website

The wedding invitation website project is located in the [`abhinash-shikha-wedding`](./abhinash-shikha-wedding/) directory.

### Quick Start:
```bash
cd abhinash-shikha-wedding
npm install
npm run dev
```

To build for production:
```bash
cd abhinash-shikha-wedding
npm run build
```

See the [abhinash-shikha-wedding README](./abhinash-shikha-wedding/README.md) for full documentation, configuration, and deployment guides.
